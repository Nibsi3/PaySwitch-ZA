# PaySwitch-ZA

A comprehensive WordPress plugin for managing, testing, switching, comparing, and optimizing multiple South African payment gateways from a single unified dashboard.

## Overview

**PaySwitch-ZA** is designed for South African e-commerce businesses to simplify payment gateway management. The plugin provides a unified interface to manage 9 major payment gateways, with intelligent routing, automatic failover, performance monitoring, and cost optimization features.

## Key Features

### Core Features
- ✅ **9 Supported Gateways**: Payfast, Ozow, Yoco, Peach Payments, PayGate, Paystack ZA, SnapScan, Zapper, Stitch
- ✅ **Unified Dashboard**: Manage all gateways from one interface
- ✅ **Easy Configuration**: Test/live mode switching with automatic credential validation
- ✅ **Connection Testing**: Sandbox testing with health scores and response time monitoring
- ✅ **Transaction Logging**: Comprehensive logging of all payment attempts
- ✅ **Gateway Comparison**: Compare fees, success rates, and performance metrics

### Premium Features
- 🔒 **Multiple Gateways**: Enable all 9 gateways simultaneously
- 🔒 **Advanced Analytics**: Comprehensive analytics dashboard with comparison charts
- 🔒 **Smart Routing**: Automatic failover and load balancing
- 🔒 **Optimization Engine**: AI-powered optimization suggestions for better performance
- 🔒 **Fee Monitor**: Daily fee tracking and cost optimization recommendations
- 🔒 **Uptime Monitor**: Hourly gateway availability checks and downtime tracking
- 🔒 **Unlimited Logging**: Full transaction history without limits
- 🔒 **Performance Metrics**: Track success rates, approval rates, and response times

## Quick Start

1. **Install the Plugin**
   - Upload to WordPress plugins directory
   - Activate through WordPress admin

2. **Configure Your First Gateway**
   - Navigate to **PaySwitch ZA** in admin menu
   - Click **Configure** on your desired gateway
   - Enter API credentials (test or live mode)
   - Save and enable

3. **Set as Default**
   - Click **Set as Default** to make it your primary payment method

4. **Test Connection**
   - Go to **Testing** tab
   - Click **Run Test** to verify connectivity
