Manage, test, switch, and optimize South African payment gateways for WooCommerce.

== Description ==

SA Payment Gateway Switcher is a comprehensive WordPress plugin that allows South African store owners to install, manage, test, switch, compare, and optimize multiple payment gateways in one unified interface.

**Supported Gateways:**
* Payfast
* Ozow
* Yoco
* Peach Payments
* PayGate
* Paystack ZA
* SnapScan
* Zapper
* Stitch

**Key Features:**

* **Unified Gateway Management** - Enable/disable and configure multiple payment gateways from one dashboard
* **Easy Switching** - Change your default payment gateway with one click
* **Sandbox Testing** - Test each gateway's connection, response time, and health before going live
* **Transaction Logging** - Track all payment attempts with detailed logs
* **Gateway Comparison** - Compare fees, success rates, and performance metrics
* **Failover Routing (Premium)** - Automatically route failed payments to backup gateways
* **Premium Licensing** - Monthly and lifetime license options with feature unlocking

**Free Features:**
* Enable one gateway at a time
* Basic transaction logs (20 entries)
* Sandbox testing
* Gateway configuration

**Premium Features:**
* Multiple gateways enabled simultaneously
* Advanced analytics and comparison charts
* Automatic failover routing
* Unlimited transaction logs
* Load balancing
* Scheduled daily tests
* Performance optimization suggestions

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/sa-payment-gateway-switcher` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Ensure WooCommerce is installed and activated.
4. Navigate to 'SA Gateways' in the WordPress admin menu.
5. Configure your payment gateways by clicking 'Configure' on each gateway card.
6. Enable the gateways you want to use and set one as default.

== Frequently Asked Questions ==

= Do I need WooCommerce? =

Yes, this plugin requires WooCommerce to be installed and activated.

= Can I use multiple gateways at once? =

Free users can enable one gateway at a time. Premium users can enable multiple gateways simultaneously with failover routing.

= How do I test a gateway? =

Go to the 'Testing' tab in the plugin dashboard and click 'Run Test' for any configured gateway. This will test the connection, DNS, TLS, and webhook endpoints.

= What happens if my license expires? =

You'll have a 7-day grace period. After that, premium features will be locked and you'll revert to free features.

= How do I activate my premium license? =

Go to the 'Premium' tab, enter your license key, and click 'Activate'. The plugin will validate your license with our license server.
